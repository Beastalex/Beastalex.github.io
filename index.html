Freelance Operations

I build web interfaces the way a security professional approaches code — with discipline, intentionality, and zero tolerance for unnecessary complexity. My stack is deliberately native: HTML5, CSS3, and ES6+ JavaScript, chosen not out of habit but because clean, framework-free code is faster, more maintainable, and fundamentally more auditable.

Heavy frameworks ship megabytes of dependencies, expand the attack surface, and introduce supply-chain risk. A handcrafted native codebase means every line has a purpose — no hidden abstractions, no phantom CVEs lurking in a node_modules folder. The same mindset that guides my approach to threat modeling guides my approach to front-end architecture: reduce surface area, eliminate dead weight, and build only what the system actually needs.

Every site I deliver is fully responsive, semantically correct, and optimised for performance. If it doesn't load fast on a 4G connection and render cleanly on a 320 px viewport, it isn't finished.

Whether you need a sharp landing page, a multi-section portfolio, or a custom interactive component, the output is always the same: precise, performant, and built to last without a framework to maintain.
