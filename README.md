## 📡 Overview
This repository contains the source code for my personal portfolio and freelance web development hub. Designed with a strict "tech-professional" and tactical Red/Blue teaming aesthetic, the site serves as a digital resume, a technical project showcase, and a secure contact portal.

## 🏗️ Architecture & Stack
This project was built using a strictly native, framework-free architecture. It is designed to minimize attack surface, eliminate dependency bloat, and guarantee maximum performance.

* **HTML5:** Semantic, accessible structuring.
* **CSS3:** Custom variables, responsive grid/flexbox layouts, and dynamic animations.
* **Vanilla JavaScript (ES6+):** Form handling, scroll reveals, and interactive components.
* **Hosting:** GitHub Pages.
* **Form Handling:** Formspree API integration.

## ⚙️ Core Features
* **The 4-D Methodology Matrix:** A grid layout detailing my analytical approach to cybersecurity (Deconstruct, Diagnose, Develop, Deliver).
* **Labs & Operations Showcase:** Categorized breakdowns of my active and planned Red/Blue team environments.
* **Freelance Operations Portal:** Transparent pricing and service offerings for native web development.
* **Responsive Design:** Fluid layout adapting perfectly from ultra-wide desktop monitors to 320px mobile viewports.
* **Terminal Access (Easter Egg):** A custom-built, hidden command-line interface featuring an automated boot sequence and tactical logging.
